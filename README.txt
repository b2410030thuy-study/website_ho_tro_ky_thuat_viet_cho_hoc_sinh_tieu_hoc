======================================================
HƯỚNG DẪN SỬ DỤNG WEBSITE BÉ TẬP VIẾT TIẾNG VIỆT LỚP 1
======================================================

1. CÁCH KHỞI ĐỘNG CHẠY LOCAL:
- Bước 1: Đảm bảo bộ phông chữ HP001 đã nằm trong thư mục /fonts/ như cấu trúc mô tả.
- Bước 2: Click đúp trực tiếp vào file `index.html` để mở bằng trình duyệt Web (Chrome, Edge, Firefox...). Không cần kết nối Internet.

2. TÀI KHOẢN ĐĂNG NHẬP MẶC ĐỊNH:
- Giáo viên: 
  + Mã số: GV001
  + Mật khẩu: 123456
- Học sinh: 
  + Mã số: HS001
  + Mật khẩu: 123456

3. TÍNH NĂNG CHÍNH:
- Học Sinh: Luyện tập 29 chữ cái Tiếng Việt chuẩn tiểu học, xem Animation viết từng nét, tự tô/viết bằng Chuột/Cảm ứng trên khung Ô Ly, nghe giọng phát âm vi-VN và tham gia Mini-game cộng sao.
- Giáo Viên: Theo dõi số lượng học sinh, danh sách sao thưởng và Tạo phiếu in bài tập Tiếng Việt chuẩn khổ giấy A4 (chuẩn font HP001 local).
